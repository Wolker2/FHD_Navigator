# FHD_Navigator 0.2.4 — AUTOPILOT_OPEN_TEST

**Новая отдельная тестовая версия.** Старую версию 0.2.1 не заменяет.

[Оригинальный ZIP для установки](install/FHD_Navigator_0.2.4_AUTOPILOT_OPEN_TEST.zip) — 50 080 байт, 11 файлов. SHA-256: `32e6896708c0ecff507570b79d5bfc3f52b9955654c8501acb3fa91c54b6fa60`.

## Что внутри

- `SOURCE/ORIGINAL_TEXT`: исходные `Main.txt`, `Lang.txt`, `CacheData.txt` — **взяты непосредственно из установочного архива**, сохранены побайтно.
- `SOURCE/DAT_JSON`: три DAT в редактируемом JSON с проверенным обратным кодированием.
- `SOURCE/ORIGINAL_GI`: четыре оригинальных файла GI — `AutopilotA`, `AutopilotD`, `AutopilotN`, `RouteFrame`.
- `SOURCE/PNG`: четыре редактируемых PNG, созданных из GI.
- `SOURCE/ModuleInfo.utf8.txt`: редактируемый ModuleInfo (в оригинальном архиве кодировка Windows-1251).
- `tools/build_source.py`: скрипт подготовки исходников и сборки установочного ZIP.
- `tools/dat_codec.py`: формат BlockPar/CacheData.
- `ORIGINAL_FILE_SHA256.json`, `SOURCE_HASHES.json`, `VALIDATION_REPORT.json`: контрольные суммы и результаты проверок.

Для пересборки без изменений: `python tools/build_source.py --verify`. Для сборки изменённых GI/PNG требуется `srhd_modkit` (XenoModKit). При отсутствии правок сборка воспроизводит оригинальный ZIP побайтно. При правках заменяются только затронутые записи ZIP; остальные остаются неизменными.

**Важно:** игровые DAT обновляются при редактировании `DAT_JSON/*.json`. Редактирование файлов `ORIGINAL_TEXT/*.txt` само по себе **не** компилирует DAT; исходные текстовые файлы хранятся для разработки и изучения. PNG — производные изображения, при повторной конвертации их формат может отличаться от оригинального GI; оригинальные GI сохранены.

В исходном ZIP есть механизм показа кнопки автопилота при работе с маршрутом, но это **не доказывает** его работу с конкретной версией автопилота или любым EXE. Данный пакет — **TEST**. Игра не запускалась; автоматические проверки не являются игровыми тестами.
